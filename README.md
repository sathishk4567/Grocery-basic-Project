# Python Grocery Billing System 🛒

A beginner-friendly Python grocery billing program created as a practical
project while revisiting Python programming fundamentals.

## Features

- Customer name input
- Item code-based selection
- Multiple items in a single bill
- Quantity-based price calculation
- Running grand total
- 10% discount for bills above ₹500
- Final payable amount calculation
- Print bill / No Bill option
- Checkout using item code `9999`

## Items

| Item Code | Item | Price |
|-----------|------|-------|
| 1001 | Rice | ₹60/kg |
| 1002 | Sugar | ₹50/kg |
| 1003 | Oil | ₹150/litre |
| 1004 | Milk | ₹30/litre |
| 9999 | Finish Billing | - |

- `if / elif / else`
